Prüfe Seite …

Diese Seite legt Tabellen, Spalten, Rechte und den Datei-Speicher in Appwrite automatisch an. Du brauchst dafür einen temporären API-Schlüssel:

  1. Appwrite → dein Projekt → Overview → Integrations → API keys → Create API key, Name „setup“.
  2. Bei den Scopes alle Einträge unter Database/Tables, Storage und Users anhaken (lieber zu viele als zu wenige). Create.
  3. Den „Secret“ des Schlüssels kopieren und unten einfügen. Er wird nur in deinem Browser benutzt und nirgends gespeichert.
  4. Danach den Schlüssel in Appwrite wieder löschen.

Vorher: (ohne Schlüssel – zeigt, ob Appwrite diese Seite akzeptiert)
